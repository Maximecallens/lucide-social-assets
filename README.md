# Lucide social assets

Visuels publics des posts LinkedIn / Instagram de Lucide (lucide.finance), générés automatiquement par Claude.

- `tools/render.py` : rendu des visuels à la charte Lucide (voir la docstring pour le format de `spec.json`).
- `posts/<AAAA-MM-JJ>_<id>/` : un dossier par post (spec.json, linkedin.png, instagram.jpg, linkedin.txt, instagram_caption.txt).

URL publique d'une image : `https://raw.githubusercontent.com/Maximecallens/lucide-social-assets/main/posts/<dossier>/linkedin.png`
